# Sigla di avvio

Metti qui il file audio della sigla con il nome esatto `theme.mp3`.
Viene riprodotto dal browser a basso volume per ~20 secondi con fade-out, senza toccare Spotify o altri player.
Se il file manca la casella nel BootScreen si disattiva da sola.

Il file audio non va in Git (vedi .gitignore).
